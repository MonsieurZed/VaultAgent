À quoi sert un client ?

Ce n’est pas un autre compte du coffre : c’est le petit programme qui remplit les champs là où votre agent travaille.

  1. Installer sur l’appareil utilisé par l’agent
    Client Windows · sans service SHA256Client Linux · autonome SHA256
  2. Créer un code ci-dessous et le saisir dans le programme du client.
  3. Cliquer sur Autoriser les clients en haut de cette page pour permettre le remplissage.

Le client ne conserve pas votre mot de passe maître. Il garde seulement une autorisation que vous pouvez révoquer.

Saisissez ce code dans le client. Usage unique, valable cinq minutes. Ne le collez pas dans un chat.

Ce que protège le remplissage

Les mots de passe et codes TOTP sont déchiffrés dans le helper du client et remplis sans presse-papiers. L’agent reçoit seulement une confirmation.

Un agent qui contrôle entièrement le navigateur peut encore lire un champ rempli. Ce mécanisme évite l’affichage des secrets dans le flux normal ; il ne protège pas contre du code arbitraire malveillant.

Authentik protège l’administration. Chaque client possède une autorisation distincte et révocable. Aucun accès brut aux secrets n’est proposé.
